# SQUID (スクイッド) - GAME & WATCH WIDE SCREEN (Model SQ-22)

1981年に発売された任天堂のゲーム＆ウォッチ ワイドスクリーンシリーズの名作『オクトパス（OC-22）』をモチーフにした、スマートフォン・PC対応の液晶風電子ゲーム『スクイッド（SQUID）』です。

## 特徴
- **実機さながらの反射型液晶（TN-LCD）表現**:
  - 偏光板のオリーブグリーン背景、カラー印刷シート層（サルベージ船・岩礁・沈没船・黄金の宝箱）、非点灯ゴーストセグメント、点灯時のドロップシャドウまで緻密に再現。
- **本家『オクトパス』準拠のゲームルール＆ピエゾ圧電ブザー音**:
  - **財宝獲得（+1点）**: 右下の宝箱（ポジション5）で `RIGHT ▶` を押すたびに財宝を袋に詰めて **+1点**（何度でも連続獲得可能）。
  - **船への生還ボーナス（+3点）**: 財宝を1個以上持って左上の船まで戻ると、宝袋を高々と掲げて **+3点**！
  - **捕まりバタバタ演出**: 巨大イカの4本の触腕（4段・5段・4段・3段）の先端に触れると、懐に抱え込まれて手足をバタバタさせる名物ミス演出が発生。
  - **200点・500点ボーナス**: 200点および500点到達時にファンファーレとともにミスが帳消しになり、船上の待機ダイバー（残機）が3人に完全復活。
  - **GAME A / GAME B / TIME**: 標準スピードの `GAME A`、高速かつフェイント（切り返し）が増える上級者向け `GAME B`、時計＆AIデモプレイの `TIME` モードを搭載。
- **グローバルランキング ＆ 遊んだ人の地名記録**:
  - Cloudflareのエッジ位置情報 (`request.cf.city`, `request.cf.region`, `request.cf.country`) およびGeo APIフォールバックにより、プレイした人の地名（市区町村・地域・国旗）を自動記録。
  - **個人ハイスコア（ALL / GAME A / GAME B）**、**地域別（CITY）ランキング**、**アベレージ（AVERAGE）ランキング**の3タブを搭載。

## GitHub + Cloudflare デプロイ手順

### 方法1：Cloudflare Workers & Pages で GitHub リポジトリを直接デプロイ（推奨・1つのプロジェクトで完結）
1. このフォルダを GitHub リポジトリへ push します。
2. Cloudflare Dashboard -> **Workers & Pages** -> **作成** から GitHub リポジトリを接続してデプロイします（`wrangler.json` と `worker.js`、`functions/api/scores.js` が自動で認識されます）。
3. 永続化のため、Cloudflare の **KV** で名前空間 `SQUID_KV`（または `SCORES`）を作成し、プロジェクトのバインディング設定で変数名 `SQUID_KV`（または `SCORES`）としてバインドします。
   - ※ KVバインド前でもエッジメモリ上で即座にランキング・地名取得が動作します。

### 方法2：ランキングAPI用 Worker を単体で作成する場合
1. Cloudflare Dashboard -> **Workers & Pages** -> **Worker を作成**（名前例: `squid-api`）。
2. KV名前空間 `SQUID_KV`（または `SCORES`）を作成し、バインディング変数名 `SQUID_KV`（または `SCORES`）でバインド。
3. [worker.js](file:///C:/Users/watar/OneDrive/デスクトップ/AIgames/Squid/worker.js) のコードを貼り付けてデプロイします。
